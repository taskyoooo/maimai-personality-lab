# 麦麦人格实验室

**今天，吃出哪种自己。** 一份可安装的 Skill，以及一个无第三方依赖、仅在本机运行的口味与预算实验室。

把「经典、鲜辣、清爽、甜蜜、咖啡」五种主动选择的偏好，变成娱乐口味画像；结合真实 MCP 菜单报价给出预算内候选，并导出不含账户信息的 SVG 灵感卡。人格不决定消费，用户的预算和偏好决定推荐。

## 目标用户

想减少选择负担、控制单次预算，或分享今天口味灵感的麦当劳用户；也适合希望让 AI 推荐有数据出处的 Skill 使用者。

## 快速开始

需要 Python 3.10 或更新版本，无需安装第三方依赖。

```sh
git clone https://github.com/taskyoooo/maimai-personality-lab.git
cd maimai-personality-lab
python3 scripts/lab.py
```

在浏览器打开 http://127.0.0.1:8765 。选择偏好和预算，点击「生成我的灵感」，再下载分享卡。

- **演示模式**：开箱可运行，所有示例组合与金额均为虚构，页面与分享卡明确标注，不能用于点餐。
- **真实模式**：用户自行在 https://open.mcd.cn/mcp 完成授权，将 Token 填入本机密码框，点击「连接并发现工具」。工具 schema 和参数工作台让 AI 或开发者依据实际返回值查询并建立候选。当前不是无需配置的一键自动点餐产品。

真实接入步骤、工具白名单、能力限制与核验状态见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。未完成 Token 授权前不宣称真实业务调用成功。

## 使用示例

「今天偏爱经典，预算30元，排除辣味，帮我做一张麦麦灵感卡。」

演示会生成「经典守护者」，给出标注为演示的预算内候选。接入真实 MCP 后，通过门店菜单或完整组合试算结果建立候选，推荐器优先口味匹配，再比较预算余量。超预算、排除标签或超过15分钟的真实候选不会进入结果。没有匹配项时明确返回空结果。

## 作为 Skill 安装

将仓库复制到客户端的技能目录，保持 `SKILL.md`、`scripts/`、`web/` 与集成文档的相对位置。支持本地 Skill 的客户端可按其文档加载。Codex 示例：将整个仓库目录放至 `~/.codex/skills/maimai-personality-lab` 后重新发现技能。也可直接让智能体阅读仓库根目录的 `SKILL.md`。不要把 Token 放进 Skill 文件或 MCP 示例配置。

## 实现特点

- 标准 MCP Streamable HTTP：initialize、初始化通知、分页 tools/list、tools/call，支持 JSON 与 SSE 响应解析。
- 仅允许实际发现且在只读白名单内的工具，不暴露任意 URL 或任意工具执行接口。
- 名称和报价从真实记录的 JSON Pointer 提取，金额按分计算；口味标签为人工判断。
- 本机服务绑定 127.0.0.1，校验 Host、Origin 和随机会话头；不记录请求、凭证或原始结果日志。
- Token 与原始业务数据仅在内存，断开可清除；偏好仅在用户选择时保存在浏览器，可清除。
- SVG 文本转义，页面动态内容使用 textContent，分享卡不包含查询记录或身份信息。

## 验证
